# Lumi

Lumi para Android, Android TV e Google TV.

## Baixar

**Link direto (sempre a versão mais nova):**

https://github.com/Adriano-Martins27/lumi-app/releases/latest/download/lumi.apk

## Instalar na TV (Google TV, Android TV, TV Box, Fire TV)

1. Instale o app **Downloader** (da AFTVnews) pela loja da TV.
2. Em Configurações → Apps → Downloader, permita **instalar apps desconhecidos**.
3. Abra o Downloader, digite o link acima e confirme.
4. Quando o download terminar, toque em **Instalar**.

## Instalar no celular

Abra o link acima no navegador do celular, baixe o arquivo e toque nele para instalar (permita instalar de fontes desconhecidas se o Android pedir).
